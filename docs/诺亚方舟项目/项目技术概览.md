## 一、项目简介

**诺亚保管库**是一套基于多模态生物识别技术的**身份认证终端系统**，部署在专用硬件设备上，用于对进出人员进行高安全级别的身份验证。系统支持**密码、胁迫码、虹膜、掌纹**四种认证方式的任意组合，并与上级管理平台（IAMS）通过 MQTT 协议实时联动。

### 核心场景

1. **组合认证**：人员可按预设顺序依次完成密码→虹膜→掌纹等多步认证，全部通过后方可通行
2. **单独认证**：也支持单一认证方式独立使用
3. **凭证远程管理**：IAMS 通过 MQTT 下发凭证添加/更新/删除指令，设备自动同步到虹膜和掌纹硬件
4. **通行记录上报**：认证成功后记录通行日志并上报给 IAMS
5. **设备状态心跳**：每 10 秒向 IAMS 发送心跳，报告设备在线状态

### 典型用户

- **现场使用人员**：通过触控屏完成身份认证
- **管理员**：通过密码进入后台管理系统，管理设备、凭证、查看通行记录和日志
- **IAMS 平台运维**：通过 MQTT 远程管理凭证和设备

### 架构特点

- **Electron + Next.js 融合**：Electron 作为壳，内嵌 Next.js 作为 Web 框架，同时提供前端 UI 和后端 API
- **本地 SQLite 数据库**：所有凭证、通行记录、设备配置、系统设置均存储在本地
- **MQTT 实时通信**：与 IAMS 平台通过 MQTT 协议双向通信，接收凭证指令、上报状态和通行记录
- **设备直连**：虹膜和掌纹识别设备通过本地 HTTP API 直接连接，不经过网络

## 五、关键业务流程

### 5.1 凭证下发流程

```
IAMS 平台 ──MQTT──► 本系统 (lib/mqtt-client.ts)
                           │
                    解析指令 (passport-add/update/del)
                           │
                    ┌──────┴──────┐
                    ▼             ▼
              虹膜设备(HTTP)  掌纹设备(HTTP)
                    │             │
                    ▼             ▼
              写入 SQLite   写入 SQLite
```

### 5.2 组合认证流程

```
输入身份编码 → 查询数据库获取认证类型列表
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
    密码验证    虹膜识别    掌纹识别
    (虚拟键盘)  (设备轮询)  (设备轮询)
        │           │           │
        └───────────┴───────────┘
                    │
              所有步骤完成？
                    │
                    ▼
            写入通行记录 → 上报 IAMS → 显示成功页
```

### 5.3 通行记录上报流程

```
认证成功 → 写入本地数据库 (db-pass-logs.ts)
                    │
                    ▼
        异步调用 uploadPassLog()
                    │
                    ▼
        POST 到 IAMS 接口 → 标记已上传
                    │
        (失败则标记未上传，后续重试)
```

| 字段 | 类型 | 说明 |
|------|------|------|
| credential_id | TEXT PK | 凭证 ID |
| person_id | TEXT | 人员编码 |

## 九、安全设计

1. **AES 加密存储**：密码凭证内容使用 AES 加密后存入数据库
2. **胁迫码机制**：胁迫码触发时静默记录通行，表面显示认证成功
3. **管理员密码保护**：后台管理需通过密码验证，支持密码修改
4. **本地数据库**：所有数据存储在本地，不依赖外部数据库服务
5. **MQTT 认证**：连接 IAMS Broker 使用用户名密码认证
